A gentle boundary, not a cage

  1. Draw the safe zoneSet the home location and a radius from 50 m to 2 km.
  2. Walk freelyPlanned-outing mode pauses alerts for a set time, so a family trip never sounds an alarm.
  3. Know instantlyLeaving the zone alerts the family; returning home sends a calm all-clear.

Privacy and honesty

Secure by design. Honest about what is simulated.

LivedIn is a working prototype. Every device feature (GPS chip, SOS button, battery, medicine box) is a software simulation, and we never claim real hardware is connected. All names and records are fictional demo data.

  • Hashed sign-in with lockoutSalted, iterated SHA-256 digests; no passwords in clear text; locked after repeated failures.
  • Role-based accessEach dashboard only loads for its own role, and location sharing needs patient consent.
  • Safe by defaultStrict content security policy, auto-escaped output, validated inputs and uploads.
